## Birr Watch

This is my JavaScript project called **Birr Watch**. It is a simple website that shows live currency exchange rates for Ethiopian Birr (ETB).

## What it does

* Fetches real-time exchange rates using an API.
* Lets you convert ETB into different currencies.
* You can add currencies to a watchlist to save them.
* Saves your watchlist in the browser so it stays even if you refresh.

## Built With

* HTML
* CSS
* JavaScript

## How to use

1. Download or clone this repository.
2. Open the index.html file in your web browser.
